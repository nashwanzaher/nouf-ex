### 4.3 Graceful Shutdown

```typescript
// ✅ يتبع expressjs.com/en/advanced/healthcheck-graceful-shutdown.html
async function gracefulShutdown(signal: string): Promise<void> {
  log.info({ msg: 'shutdown_started', signal });
  if (server) {
    await new Promise<void>((resolve) => {
      server!.close(() => resolve());
      setTimeout(() => {
        log.warn({ msg: 'shutdown_force_exit' });
        resolve();
      }, 10_000).unref();
    });
  }
  try {
    await db.close();
  } catch (err) {
    log.warn({ msg: 'db_close_error', error: (err as Error).message });
  }
  log.info({ msg: 'shutdown_complete' });
  process.exit(0);
}
```

**التقييم:** ✅ ممتاز — يتبع best practices

### 6.1 مشاكل حرجة (Critical)

#### C-1: `TFunction` غير مصدّر من react-i18next
**الملف:** `src/components/ErrorBoundary.tsx:20`  
**المصدر:** [react.i18next.com](https://react.i18next.com/latest/typescript)  
**الحل:** استيراد `TFunction` من `i18next` بدلاً من `react-i18next`

```typescript
// ❌ الحالي
import type { TFunction } from 'react-i18next';

// ✅ المقترح
import type { TFunction } from 'i18next';
```

#### C-2: `formRef` غير معرّف في SellerProducts
**الملف:** `src/pages/seller/SellerProducts.tsx:291-298`  
**المصدر:** [react.dev/reference/react/useRef](https://react.dev/reference/react/useRef)  
**الحل:** تعريف `formRef` باستخدام `useRef`

```typescript
// ✅ أضف في بداية المكون
const formRef = useRef<HTMLFormElement>(null);
```

### 6.2 مشاكل متوسطة (Medium)

#### M-1: `string | undefined` في Addresses.tsx
**الملف:** `src/pages/customer/Addresses.tsx:127-133`  
**المصدر:** [typescriptlang.org/docs/handbook/2/everyday-types.html](https://www.typescriptlang.org/docs/handbook/2/everyday-types.html#union-types)  
**الحل:** استخدام `?? ''` أو optional chaining

