# ISO/IEC/IEEE 29119 — Software Testing Standards

> **Source:** [ISO/IEC/IEEE 29119](https://www.iso.org/standard/81291.html) — international standard for software testing
> **Adopted by:** Nouf-ex testing program

ISO/IEC/IEEE 29119 supersedes older regional standards (IEEE 829, BS 7925)
and provides a unified vocabulary + process model for testing.

---

## 📚 The Five-Part Standard

| Part | Title | Purpose |
|------|-------|---------|
| 29119-1 | Concepts & Definitions | Vocabulary (test case, test procedure, …) |
| 29119-2 | Test Processes | Organizational / dynamic test process models |
| 29119-3 | Test Documentation | Document types (replaces IEEE 829) |
| 29119-4 | Test Techniques | Specification-based, structure-based, experience-based |
| 29119-5 | Keyword-Driven Testing | Test specification using standardized keywords |

## 🧪 29119-4 Test Techniques in Use

| Technique | Description | Nouf-ex example |
|-----------|-------------|-----------------|
| **Equivalence Partitioning** | Divide inputs into classes that should behave the same | `quantity=0`, `quantity=1`, `quantity=999` in cart tests |
| **Boundary Value Analysis** | Test at the edges of equivalence classes | `limit=0`, `limit=1`, `limit=100`, `limit=101` in catalog |
| **Decision Table Testing** | Cover combinations of conditions | 2FA flow: password×verified×totp×backup |
| **State Transition Testing** | Cover state changes + invalid transitions | Order state machine: pending→confirmed→processing→shipped→delivered |
| **Use Case Testing** | End-to-end user scenarios | Cart→Coupon→Order→Payment→Review flow |
