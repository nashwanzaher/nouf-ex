# Alibaba Design Study for Nouf-ex Rebuild

## Screenshot Analysis of Alibaba.com (2025-2026)

### Homepage Layout
1. **Header (White bg):** Logo (orange), Language/Currency selector (top right), Cart icon, Login/Register
2. **Sub-nav (Orange bg):** Categories, Verified Manufacturers, Trade Assurance, Accio Work, Tax Exemption, Buyer Center
3. **Main nav (White bg):** AI Mode* | Products | Manufacturers(Verified) | Global Supply
4. **Hero Search Bar:** Large rounded search input with categories dropdown, Image search icon, Orange Search button
5. **Left Sidebar:** Categories list (服装与配饰, 消费电子产品, etc.) with icons and arrows
6. **Hot Searches:** Product images with labels (摩托车, 男鞋, 玩具, etc.)
7. **Product Cards Grid:** Image, Title, Price range (¥X-¥Y), MOQ, Sold count, Country (CN), Years badge
8. **Trust Section:** 3.4W+ 认证制造商, 5,000+ 行业覆盖, 78 专属服务
9. **Footer:** Links to AliExpress, 1688, Tmall, Alipay, Lazada, etc.

### Login Page Layout
1. **Left side:** Hero image with people in warehouse, "GLOBAL B2B SOURCING WITH TRANSACTION SECURITY AND GREAT SAVINGS" headline, orange "View more" CTA
2. **Right side:** Clean login card with Account input, Password input, Forgot password link, Orange "Sign in" button, Mobile number sign in, Social login (Taobao, Google, Facebook, LinkedIn), Create account link
3. **Footer:** Family sites links, copyright

### Design System (Alibaba-style)

#### Colors
- **Primary:** #FF6A00 (Alibaba Orange)
- **Primary Hover:** #E55F00 (Darker Orange)
- **Background:** #FFFFFF (White)
- **Surface:** #F7F8FA (Light Gray)
- **Text Primary:** #333333 (Dark Gray)
- **Text Secondary:** #666666 (Medium Gray)
- **Text Muted:** #999999 (Light Gray)
- **Border:** #E5E5E5 (Light Border)
- **Accent Blue:** #1688C9 (Links, secondary actions)
- **Success:** #4CAF50
- **Warning:** #FF9800
- **Danger:** #F44336

#### Typography
- **Font:** System sans-serif (Inter, -apple-system, BlinkMacSystemFont)
- **Headline:** 24-32px, Bold, #333
- **Subheadline:** 18-20px, Medium, #333
- **Body:** 14-16px, Regular, #666
- **Caption:** 12-13px, Regular, #999
- **Price:** 16-18px, Bold, #FF6A00

#### Components
- **Search Bar:** Large, rounded, white bg, categories dropdown, orange search button
- **Product Card:** White bg, rounded corners, image, title (2 lines), price range, MOQ, sold count, country badge, years badge
- **Button Primary:** Orange bg, white text, rounded
- **Button Secondary:** White bg, orange border, orange text
- **Input:** White bg, gray border, rounded
- **Category List:** Icon + Text + Chevron right, hover highlight

#### Layout
- **Max Width:** 1200px centered
- **Grid:** 4-5 columns for products
- **Spacing:** 8px base unit
- **Border Radius:** 4-8px for cards, 20-24px for search bar

#### Key Features to Clone
1. Mega category dropdown in navbar
2. Large hero search with category selector
3. Product cards with MOQ, sold count, country
4. Left sidebar categories on homepage
5. Hot searches section
6. Trust badges section
7. Orange CTA buttons
8. Clean login with social login
9. Trade Assurance trust elements
10. Verified Manufacturer badges
