## 5. Known issues & remaining work

### High priority (block production)

1. **Commit & push the 2026-07-14 fix branch.** The local working tree
   has 20+ files of uncommitted work that include security-relevant
   changes (docker-compose `DATABASE_URL` rewrite, new vitest config
   loading `.env`). If lost, the project falls back to its pre-session
   broken state.

2. **35 frontend test failures need triage.** Of the 34 remaining
   failures:
   - 24 are DOM-content drift (Footer, Login, Register, etc.) — fix by
     updating test assertions to the new strings, or by adding a missing
     `data-testid`.
   - 3 are real bugs in `SellerProducts`, `SellerOrders`,
     `SellerAnalytics` — they render an empty object as a child, which
     crashes React.
   - 7 are accessibility expectations that need either a re-render
     trigger or a code change to expose `aria-current="step"`,
     `role="status"`, etc.

3. **`apps/e2e/run-all.ps1` is missing.** The script
   `pwsh -NoProfile -File ./run-all.ps1` referenced in
   `apps/e2e/package.json` does not exist. The 18 individual `phase*.ps1`
   scripts still work. Either create `run-all.ps1` to invoke them in
   sequence, or drop the `test` script from `apps/e2e/package.json`.

### Medium priority (next sprint)

4. **5 of 8 `scripts/quality/*.ps1` reference the legacy `app/` path.**
   `test.ps1`, `typecheck.ps1`, `lint.ps1`, `format.ps1`,
   `format-check.ps1` all do `Set-Location $PSScriptRoot\..\app`. After
   the 2026-07-11 restructure, the `app/` directory is gitignored and
   empty. They need to point at the repo root (`Set-Location $PSScriptRoot\..\..`)
   or be removed entirely in favour of `npm run test` / `npm run typecheck`.

5. **`scripts/quality/verify-fresh.cjs` requires `app/node_modules/pg`.**
   Same root cause — replace the hard-coded `app/node_modules/pg` with
   `path.join(__dirname, '..', '..', 'node_modules', 'pg')`.

6. **`scripts/quality/test-stack.ps1` only probes 5 endpoints.** It does
   not assert response shape or status. Consider extending it to validate
   the JSON body of `/api/stats/home`, `/api/products`, `/api/categories`.

7. **6 root-level stale markdown files** (`DOCUMENTATION_INDEX.md`,
   `EXAMINATION_COMPLETE.md`, `FIX_GUIDE.md`, `PROJECT_HEALTH_REPORT.md`,
   `PROJECT_MANAGEMENT.md`, `TECH_STACK_SUMMARY.md`) are dated
   2025-02-17 and reference the legacy `app/` layout, Turbo 2.5.0 (actual
   2.10.4), etc. Either delete or refresh them with 2026-07-14 numbers.

### Low priority (nice-to-have)

8. **Add `lint` and `typecheck` job for `apps/mobile`** in CI. The mobile
   workspace is currently excluded from CI workflows (its `tsconfig.json`
